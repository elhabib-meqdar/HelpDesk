# HelpDesk
sprint 2 premier brief
HelpDesk — Atlas Solutions
1. Présentation du projet
HelpDesk est une application web de gestion des demandes de support informatique développée dans le cadre d'un projet individuel pour l'entreprise fictive Atlas Solutions.

Elle permet de consulter, d'ajouter et de supprimer des demandes de support informatique directement depuis le navigateur, sans backend ni base de données.

2. Technologies utilisées
HTML5 : structure de la page et formulaire.
CSS3 : mise en forme et responsive design.
JavaScript Vanilla : gestion des demandes et manipulation du DOM.
Git et GitHub : versionnement et hébergement du code.
Jira : organisation et suivi des tâches.
3. Fonctionnalités
Affichage dynamique des demandes sous forme de cartes.
Ajout d'une demande avec validation des champs.
Suppression d'une demande avec confirmation.
Compteur dynamique du nombre de demandes.
Attribution d'un identifiant unique à chaque demande.
Interface responsive adaptée aux mobiles, tablettes et ordinateurs.
Chaque demande contient un titre, une description, une catégorie (Matériel, Logiciel ou Réseau) et une priorité (Basse, Normale ou Haute).

5. Installation et lancement
Cloner le dépôt GitHub :
git clone <URL_DU_DEPOT_GITHUB>
Accéder au dossier du projet :
cd HelpDesk
Ouvrir index.html dans un navigateur ou utiliser l'extension Live Server de Visual Studio Code.
6. Technologies et concepts JavaScript
Le projet utilise un tableau d'objets pour stocker les demandes, des fonctions pour gérer les opérations, addEventListener() pour les événements et la manipulation du DOM pour actualiser l'affichage sans recharger la page.

7. Gestion du projet
Le développement est réalisé individuellement. Git et GitHub permettent de suivre les modifications du code, tandis que Jira sert à organiser les user stories et à suivre l'avancement des tâches.
